
# Schedule Manager

## 1. Описание проекта

Schedule Manager — информационная система для составления,
управления и динамического изменения расписания занятий
и учебных аудиторий образовательной организации.

Система предназначена для автоматизации работы сотрудников,
отвечающих за составление расписания.

## 2. Основные возможности

- Создание и редактирование расписания занятий.
- Управление учебными группами.
- Добавление преподавателей.
- Учёт учебных аудиторий и их вместимости.
- Назначение аудиторий на занятия.
- Проверка пересечений по времени.
- Обнаружение конфликтов преподавателей и аудиторий.
- Динамическое изменение расписания.
- Просмотр расписания по группам, преподавателям и аудиториям.

## 3. Технологический стек

- Python — основной язык программирования.
- Flask — серверный веб-фреймворк.
- HTML — разметка страниц.
- CSS — оформление интерфейса.
- JavaScript — интерактивность.
- SQLite — система управления базами данных.
- Git — система контроля версий.
- GitHub — размещение исходного кода.

## 4. Структура проекта

- app/routes — обработчики веб-запросов.
- app/models — модели данных.
- app/services — бизнес-логика и алгоритмы составления расписания.
- app/templates — HTML-шаблоны.
- app/static — CSS, JavaScript и изображения.
- database — структура базы данных.
- tests — автоматизированные тесты.
- docs — техническая документация.
- .github — шаблоны задач и запросов на слияние.

## 5. Установка и запуск

Требования:
- Python 3.11 или выше.
- Git.
- Visual Studio Code.

Клонирование репозитория:

    git clone https://github.com/USERNAME/schedule-manager.git

Переход в папку проекта:

    cd schedule-manager

Создание виртуального окружения:

    python -m venv venv

Активация в Windows:

    venv\Scripts\activate

Установка зависимостей:

    pip install -r requirements.txt

Создание файла настроек:

    copy .env.example .env

Запуск приложения:

    flask --app app run --debug

После запуска открыть:

    http://127.0.0.1:5000

## 6. Работа с базой данных

В проекте используется SQLite.

Основные сущности:
- Преподаватели.
- Учебные группы.
- Аудитории.
- Дисциплины.
- Занятия.
- Расписание.

## 7. Правила разработки

- Для новых функций создавать отдельные ветки.
- Использовать понятные названия переменных и функций.
- Перед слиянием выполнять проверку кода.
- Исправления ошибок оформлять через Issues.
- Слияние изменений выполнять через Pull Request.

## 8. Безопасность

- Не публиковать пароли и секретные ключи.
- Хранить настройки в файле .env.
- Использовать .gitignore для исключения конфиденциальных файлов.
- Проверять входные данные пользователей.

## 9. Назначение проекта

Проект предназначен для повышения эффективности
составления учебного расписания, сокращения количества
ошибок и предотвращения конфликтов при распределении
преподавателей, групп и аудиторий.
